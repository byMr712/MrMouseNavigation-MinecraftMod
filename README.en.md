**[MR] Mouse Navigation** (MrMouseNavigation) is a lightweight client-side Fabric mod for **Minecraft 1.21.9**, enabling intuitive navigation using mouse side buttons across in-game interfaces. With it, the lower side mouse button (Mouse 4) acts as "Back", the upper side button (Mouse 5) acts as "Forward", and the middle mouse button (scroll wheel click) instantly sends chat messages, all without interfering with normal gameplay controls.

---

## What Does This Mod Do?

1. **Back Button (Mouse Button 4 / XBUTTON1)**:
   - **Menus & Containers (Settings, Chests, Inventory, Pause)**: Closes screen or returns to previous menu (equivalent to Esc).
   - **Books & Lecterns**: Flips to previous page (<).
   - **Recipe Book**: Flips to previous recipe page.
   - **Creative Inventory**: Switches to previous item category tab.
   - **Advancements**: Cycles to previous advancement tab.
   - **Chat**: Scrolls sent message history backward (↑).

2. **Forward Button (Mouse Button 5 / XBUTTON2)**:
   - **Books & Lecterns**: Flips to next page (>).
   - **Recipe Book**: Flips to next recipe page.
   - **Creative Inventory**: Switches to next item category tab.
   - **Advancements**: Cycles to next advancement tab.
   - **Chat**: Scrolls sent message history forward (↓).
   - **Screen History**: Returns forward into nested screens you backed out of.

3. **Middle Mouse Button (Mouse Button 3 / MMB)**:
   - **Chat**: Instantly sends message (equivalent to Enter).

4. **ModMenu Integration**:
   - Access the config screen via **ModMenu** to toggle features individually.

## Installation

1. Download MrMouseNavigation-Fabric-1.21.9-byMr712-v1.0.jar from [GitHub Releases](https://github.com/byMr712/MouseNavigation-MinecraftMod/releases).
2. Ensure you have **Fabric Loader** and **Fabric API** installed for Minecraft 1.21.9.
3. Place the .jar into your .minecraft/mods folder.
4. Launch the game!
