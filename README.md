**[MR] Mouse Navigation** (`MrMouseNavigation`) — легковесный и удобный клиентский мод для **Minecraft 1.21.3 (Fabric)**, добавляющий интуитивную навигацию боковыми кнопками мыши в интерфейсах игры. С ним нижняя боковая кнопка мыши (Mouse 4) работает как «Назад», верхняя боковая кнопка (Mouse 5) — как «Вперёд», а средняя кнопка мыши (колёсико / СКМ) позволяет отправлять сообщения в чате, не затрагивая при этом управление в самой игре.

---

## Основная задача мода

Во многих современных приложениях и браузерах боковые кнопки мыши (Mouse 4 и Mouse 5 / Back и Forward) являются стандартом для навигации назад и вперёд. Однако в ванильном Minecraft эти кнопки в интерфейсах не задействованы, и игроку приходится постоянно тянуться к клавише `Esc`, `Enter`, стрелкам клавиатуры или нажимать экранные кнопки.

**[MR] Mouse Navigation** решает эту проблему:
- **В любых интерфейсах (меню, инвентарях, контейнерах, книгах, чате)** кнопки мыши отвечают за быстрое перемещение назад и вперёд, а также отправку сообщений в чате по СКМ.
- **В игровом процессе (когда интерфейс закрыт)** мод полностью прозрачен и не перехватывает клики: кнопки выполняют ровно те действия, которые игрок назначил в стандартных настройках управления Minecraft.

---

## Что делает мод

1. **Кнопка «Назад» (Mouse Button 4 / XBUTTON1 / нижняя боковая)**:
   - **Окна и меню (Настройки, сундуки, инвентарь, пауза, выбор мира и др.)**: закрывает экран или возвращает в предыдущее меню (эквивалент клавиши `Esc`).
   - **Книги и кафедры**: перелистывает на предыдущую страницу (`<`).
   - **Книга рецептов**: переключает на предыдущую страницу рецептов.
   - **Творческий инвентарь**: переключает на предыдущую вкладку групп предметов.
   - **Экран достижений**: переключает на предыдущую вкладку достижений.
   - **Чат**: пролистывает историю отправленных сообщений назад (эквивалент стрелки `↑`).

2. **Кнопка «Вперёд» (Mouse Button 5 / XBUTTON2 / верхняя боковая)**:
   - **Книги и кафедры**: перелистывает на следующую страницу (`>`).
   - **Книга рецептов**: переключает на следующую страницу рецептов.
   - **Творческий инвентарь**: переключает на следующую вкладку групп предметов.
   - **Экран достижений**: переключает на следующую вкладку достижений.
   - **Чат**: пролистывает историю отправленных сообщений вперёд (эквивалент стрелки `↓`).
   - **История экранов**: позволяет вернуться вперёд во вложенный экран, если вы вышли из него кнопкой назад.

3. **Средняя кнопка мыши (Mouse Button 3 / СКМ / Колёсико мыши)**:
   - **Чат**: мгновенная отправка набранного сообщения в чат (эквивалент клавиши `Enter`).

4. **Интеграция с ModMenu и гибкая настройка**:
   - В меню модов (**ModMenu**) доступно удобное конфигурационное окно, где можно по отдельности включить или отключить навигацию для каждого типа интерфейсов, включить звуковой отклик или инвертировать кнопки.

| Интерфейс | Кнопка «Назад» (Mouse 4) | Кнопка «Вперёд» (Mouse 5) | Средняя кнопка (СКМ) |
| :--- | :--- | :--- | :--- |
| Обычные меню и контейнеры (Настройки, сундуки, верстак, пауза) | Закрыть / Назад (`Esc`) | Возврат вперёд по истории | — |
| Книги и кафедры | Предыдущая страница (`<`) | Следующая страница (`>`) | — |

| Творческий инвентарь | Предыдущая вкладка | Следующая вкладка | — |
| Экран достижений | Предыдущая категория | Следующая категория | — |

## Настройки (ModMenu)

При установленном **ModMenu** в настройках мода доступны следующие опции:
- **Общий переключатель**: включение/отключение работы мода.
- **Закрытие меню и экранов**: возврат назад / закрытие контейнеров.
- **История экранов**: возврат вперёд по истории открытых экранов.
- **Книги и кафедры**: навигация по страницам книг.
- **Книга рецептов**: переключение страниц рецептов.
- **Вкладки креатива**: переключение категорий предметов.
- **Достижения**: переключение вкладок ачивок.
- **История чата**: навигация по ранее отправленным сообщениям.
- **Отправка в чат по СКМ**: отправка сообщения нажатием на колёсико мыши.
- **Звуковой отклик**: воспроизведение тихого клика при навигации.
- **Инвертировать кнопки**: поменять местами Mouse 4 и Mouse 5.

Конфигурация сохраняется в файл `.minecraft/config/mousenavigation.json`.

## Установка

1. Скачайте `MrMouseNavigation-Fabric-1.21.3-byMr712-v1.0.jar` со страницы [GitHub Releases](https://github.com/byMr712/MouseNavigation-MinecraftMod/releases).
2. Убедитесь, что установлены **Fabric Loader** и **Fabric API** для Minecraft 1.21.3.
3. Поместите скачанный `.jar` файл в папку `.minecraft/mods`.
4. Запустите игру.

---

## Сборка из исходников

1. Клонируйте репозиторий и переключитесь на нужную ветку:
   ```bash
   git clone https://github.com/byMr712/MouseNavigation-MinecraftMod.git
   cd MouseNavigation-MinecraftMod
   git checkout 1.21.3
   ```
2. Выполните сборку:
   ```bash
   ./gradlew build
   ```
3. Собранный файл будет находиться в `build/libs/MrMouseNavigation-Fabric-1.21.3-byMr712-v1.0.jar`.
